UniPods Memory

Suppression des données

UniPods Memory n'enregistre ni vos questions ni votre numéro WhatsApp ou identifiant Telegram dans sa base de données.

Pour demander la suppression de vos données

  1. Contactez {{CONTACT}} en précisant « Suppression de données UniPods Memory ».
  2. Indiquez les éléments concernés (par exemple un document ajouté ou des messages vous citant dans un export de discussion).
  3. Les éléments sont supprimés de la mémoire sous 30 jours, et une confirmation vous est envoyée.

Les organisateurs peuvent aussi retirer immédiatement un document depuis l'onglet « Ajouter des documents » du site (bouton « Supprimer »).

Pour arrêter d'utiliser le bot WhatsApp ou Telegram, il suffit de ne plus lui écrire ou de le bloquer.

Data deletion

UniPods Memory does not save your questions, your WhatsApp number or your Telegram ID in its database.

To request deletion of your data

  1. Contact {{CONTACT}} with the subject "UniPods Memory data deletion".
  2. Specify what is concerned (for example an added document, or messages quoting you in a chat export).
  3. The items are removed from the memory within 30 days and you receive a confirmation.

Organisers can also immediately remove a document from the "Add documents" tab of the website ("Delete" button).

To stop using the WhatsApp or Telegram bot, simply stop writing to it or block it.
